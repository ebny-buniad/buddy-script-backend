# Buddy Script Backend

Backend server for **Buddy Script** – a social media style application where users can create posts, react, comment, and manage privacy.

---

## Project Overview

Buddy Script Backend is built using **Node.js, Express, Prisma, and PostgreSQL**.  
It provides secure authentication, user management, post handling, and interaction features.

---

## Features

-  Authentication (Better Auth)
-  User Management
-  Create / Update / Delete Posts
-  Post Privacy (Public / Private)
-  Post Reactions (Like / Dislike)
-  Comments & Comment Reactions
-  Count System (comments, reactions)
-  Role-based Authorization (User / Admin)
